# ACUVUE Professional Experience Dashboard

GitHub Pages에 바로 업로드 가능한 단일 HTML 대시보드입니다.

## 포함 파일
- index.html
- assets/korea-region-reference.jpeg

## 사용 방법
1. Repository에 파일 업로드
2. Settings > Pages > Deploy from branch > main / root 저장
3. 생성된 GitHub Pages URL 접속

## 데이터 업로드
CSV 또는 XLSX 업로드 가능. 템플릿 다운로드 버튼으로 컬럼 예시를 받을 수 있습니다.
