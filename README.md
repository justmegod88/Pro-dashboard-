# ACUVUE Professional Experience Dashboard

GitHub Pages에 바로 올릴 수 있는 정적 웹 대시보드입니다.

## 파일 구조

```
index.html
styles.css
app.js
assets/korea-region-reference.jpeg
```

## 업로드 가능한 데이터 컬럼

CSV 또는 Excel 첫 번째 시트에 아래 컬럼을 사용하세요.

- 지역
- 안경원명
- 교육완료
- 스마트피팅사용
- 구매전환
- 멀티포컬
- 난시
- FollowUp필요
- 경쟁사활동

값은 `1`, `Y`, `TRUE`, `완료`, `사용`, `구매`, `필요`, `예` 형태를 인식합니다.

## 배포

GitHub Repository에 위 파일을 그대로 올리고 Settings > Pages에서 main / root를 선택하세요.
